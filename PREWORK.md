# PREWORK — Before You Arrive

- Sign in to GitHub and confirm you can open
  `https://github.com/MalikZiglam/kestrel-detection-as-code-workshop`.
- Accept the collaborator invitation when it arrives; participants receive Write
  access so they can create branches and pull requests.
- Check your GitHub email/privacy settings. The repository is public, so your
  username, commits, reviews, and pull-request activity are publicly visible.
- Confirm the approved Copilot interface works if you plan to use it.
- Do not paste client, confidential, credential, or personal-sensitive material
  into this repository or an AI prompt. Workshop data is fictional and synthetic.
- Foundation participants need only a browser. No local Git, Python, Terraform,
  Elastic access, or infrastructure credentials are required.

Groups and participant-owned namespaces are assigned dynamically at the start of
the workshop based on actual attendance.
